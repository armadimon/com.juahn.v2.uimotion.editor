# Unity에서 확인해야 할 것

이 패키지는 `UnityEditor`를 참조하므로 CI에서 테스트할 수 없다. 검증은
`./Tools~/compile-check/run.sh`(컴파일) 하나뿐이고, **아래 항목은 컴파일로 대신할 수 없다.**

에디터 코드를 고쳤으면 관련 항목을 다시 확인한다. 확인한 날짜를 옆에 적어 둔다.

## 준비

1. 두 패키지를 프로젝트의 `Packages/` 아래에 임베드한다 (`Library/PackageCache`는 읽기 전용이라
   예시 생성이 실패한다 — 그 실패가 제대로 보고되는지도 아래에서 확인한다).
2. `Window > UI Motion > Generate Missing Samples`를 누른다.
3. `Window > UI Motion > Node Doctor`를 연다.

## 1. 노드 계약 — Node Doctor

- [ ] 노드 13개가 전부 통과로 뜬다. 통과하지 못한 것이 있으면 그 이유가 곧 남은 빚이다.
- [ ] 행을 빠르게 여러 번 클릭해도 `ArgumentException: Getting control ...`이 나지 않는다.
- [ ] "다시 검사"를 눌러도 같다.
- [ ] 배치 모드가 종료 코드 0으로 끝난다:

```bash
"/Applications/Unity/Hub/Editor/<버전>/Unity.app/Contents/MacOS/Unity" \
  -batchmode -quit -projectPath <프로젝트> \
  -executeMethod Juahn.UiMotion.Editor.MotionNodeDoctor.RunBatch
echo "exit=$?"
```

- [ ] 노드 하나의 `[MotionNode]`에서 `Summary`를 지우면 배치가 종료 코드 1로 죽는다.

## 2. 그래프 창 — 왕복 (가장 중요)

- [ ] 그래프 에셋을 더블클릭하면 창이 열린다.
- [ ] 빈 곳에서 스페이스나 우클릭으로 노드 검색 창이 뜬다.
- [ ] 줌하거나 스크롤한 상태에서도 노드가 마우스 위치에 생긴다.
- [ ] 노드를 배치하고 잇고 옮긴 뒤 저장하고 **창을 닫았다 다시 연다.** 위치·간선·**간선 순서**가 전부 그대로다.
- [ ] `Sequence`에 자식을 셋 달고 순서를 바꾼다. 화면의 번호와 실제 실행 순서가 같다(프리뷰로 확인).
- [ ] 간선을 지웠다 다시 이으면 그 자식이 맨 뒤로 가고 번호가 즉시 갱신된다.

**중복 간선 (실제로 데이터를 잃던 경로)**

- [ ] A에서 B로 **두 번** 끈다. 간선이 하나만 생긴다.
- [ ] 그 간선을 지우고 저장한 뒤 다시 연다. A의 자식이 의도대로 남아 있다.

**끝나지 않는 노드**

- [ ] `Float`이나 `Bounce`의 출력 포트가 흐리게 보이고 거기서 새 간선을 뽑을 수 없다.
- [ ] 이미 자식이 달린 상태로 저장된 그래프를 열면 그 간선이 **보이고 지울 수 있다.**

## 3. 되돌리기

- [ ] 노드를 지우고 Ctrl+Z. 노드가 파라미터까지 그대로 살아 돌아온다 (`[SerializeReference]` 구조 변경).
- [ ] 노드를 추가하고 Ctrl+Z. 사라진다.
- [ ] 간선 순서를 바꾸고 Ctrl+Z.
- [ ] 슬롯 드롭다운 변경과 슬라이더 변경이 Ctrl+Z로 돌아간다.
- [ ] 되돌리기 후 **화면이 에셋과 일치한다** (뷰가 낡은 채 남지 않는다).

## 4. 창 생명주기

- [ ] 그래프 창을 도킹·언도킹·Shift+Space 최대화한 뒤에도 검색 창이 뜬다.
- [ ] 스크립트를 고쳐 도메인 리로드를 일으킨 뒤에도 창이 편집 중이던 에셋을 다시 연다.
- [ ] 창을 닫았다 열어도 같다.

## 5. MotionPlayer 인스펙터

- [ ] 슬롯 목록이 그래프의 노드에서 계산돼 뜨고, 손으로 고칠 수 없다는 것이 화면에 보인다.
- [ ] 빈 슬롯이 눈에 띄게 표시된다.
- [ ] 자동 바인딩 두 버튼이 이름이 같은 자식을 찾아 채운다. 결과 숫자가 맞다.
- [ ] 자동 바인딩을 Ctrl+Z **한 번**으로 되돌린다.
- [ ] 그래프를 바꾸면 슬롯 목록이 따라오고, 새 그래프에 없는 바인딩이 "이 그래프에 없는 슬롯"으로 남는다.
- [ ] 그래프 교체를 Ctrl+Z **한 번**으로 되돌린다.
- [ ] 프리팹 인스턴스에서 바꾼 값이 오버라이드로 기록되고 씬 저장 후에도 남는다.
- [ ] 그래프 창에서 노드를 고치면 인스펙터의 "오류 N · 경고 M"이 따라 바뀐다.

## 6. 인에디터 프리뷰 — 에셋 오염 (가장 위험)

- [ ] 트리거 옆 "재생"이 플레이 모드 없이 실제로 움직인다.
- [ ] "정지"가 **그 트리거만** 멈춘다. 다른 트리거는 계속 돈다.
- [ ] "프리뷰 멈추기"가 대상을 프리뷰 전 상태로 정확히 되돌린다.
- [ ] **프리뷰 중에 Ctrl+S를 누른다.** 저장된 씬에 중간 값이 들어가지 않는다.
- [ ] 프리팹 스테이지에서도 같다.
- [ ] **프리뷰 중에 `Apply All Overrides`를 누른다.** 프리팹에 중간 값이 굳지 않는다.
- [ ] 프리뷰 중에 플레이 모드에 들어갔다 나온다. 대상이 원래대로다.
- [ ] 선택을 다른 오브젝트로 옮긴 뒤 `Window > UI Motion > Stop All Previews`로 멈출 수 있다.
- [ ] 연출이 끝난 뒤 에디터가 계속 바쁘지 않다 (인스펙터가 매 프레임 다시 그리지 않는다).

## 7. 프리셋 브라우저

- [ ] 프로젝트의 그래프가 전부 나온다. 검색이 이름과 트리거 이름으로 거른다.
- [ ] 행을 빠르게 클릭해도 예외가 없다.
- [ ] **"선택한 오브젝트에 적용"** — `MotionPlayer`가 붙고, 그래프가 꽂히고, 자동 바인딩이 돌고,
      그 전부가 Ctrl+Z **한 번**으로 돌아간다.

## 8. 손상된 그래프

- [ ] 노드 타입을 지우거나 이름을 바꿔 결손 노드를 만든다.
- [ ] 그래프 에셋 인스펙터에 "결손 노드 정리" 버튼이 뜬다.
- [ ] 눌러서 정리하면 검사 오류가 사라진다. Ctrl+Z로 되돌아간다.
- [ ] 그 상태에서 그래프 창을 열어도 창이 죽지 않는다.

## 9. 읽기 전용 위치

- [ ] 패키지를 `Library/PackageCache`에 둔 상태에서 `Generate Missing Samples`를 누른다.
      "13개를 만들었습니다"가 아니라 **실패했다는 오류**가 나온다.
